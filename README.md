# /root web

A web-tailored React chrome of `/root`. Uses the bundled **PALM** face, the live theme palettes, and the same wallpaper language as the desktop app — without Windows paths or window chrome. Works on phone and desktop.

A Root Account is required. The first screen sends you to [useroot.sh/account](https://useroot.sh/account) to unlock, then you continue into the harness.

```bash
cd root-web
npm install
npm run dev
```

Opens at `http://localhost:5174`. Command palette is `Ctrl+K`.
